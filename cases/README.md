# cases/

Promoted case studies — incidents that have earned a standalone markdown treatment per the [promotion criteria in CONTRIBUTING.md](../CONTRIBUTING.md#promotion-criteria--incident-to-case).

This directory ships with one seed entry — [`2026-05-20-quantitative-baseline.md`](2026-05-20-quantitative-baseline.md) — contributed by the operator who built the scaffold, as iteration-zero data. Subsequent promotions are the maintainer's call once the [handoff](../../issues/1) lands.

## Indexing

Cases are named by date and structural-property tag:

```
cases/YYYY-MM-DD-<short-tag>.md
```

The maintainer keeps a running index here as cases land.
