# incidents/

This directory exists structurally. Incidents themselves live in the issue tracker, not as files in this directory.

To file an incident: open a new issue using the [incident report template](../.github/ISSUE_TEMPLATE/incident-report.yml). The structured fields are what the corpus has converged on.

To find prior incidents: search the [issue tracker](../../issues?q=label%3Aincident), filtered by label.

Incidents that earn promotion — by the [criteria in CONTRIBUTING.md](../CONTRIBUTING.md#promotion-criteria--incident-to-case) — move to [`cases/`](../cases/) as standalone markdown files. Most incidents will remain issues. Promotion is not the goal; it is the mechanism for surfacing examples that have earned a standalone treatment.
